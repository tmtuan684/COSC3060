Tabindex Demo

Definition: Tabindex is the sequential movement order in which elements receive focus when navigating with the tab key on keyboard.
Note:
Elements with a positive tabindex are focused in ascending order. The smaller the tabindex value, the higher priority it has.
Elements with a tabindex of -1 are not focusable via the keyboard but can be focused programmatically.
